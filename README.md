# المهندس

هذا المشروع يمثل الموقع الرسمي لنشاط "المهندس للخدمات الوظيفية والأكاديمية".

## الوصف
الموقع يقدم خدمات متعددة تشمل:
- تصميم السيرة الذاتية الاحترافية المتوافقة مع ATS
- التقديم للوظائف الخليجية
- إعداد خطابات التقديم الوظيفي
- التقديم للمنح الدراسية
- تصميم البوسترات والإعلانات التجارية
- تنسيق البحوث والكتب والمجلات
- تحليل البيانات باستخدام Power BI
- تصميم وتطوير المواقع الإلكترونية
- الحلول الرقمية والتعليمية والوظيفية والتقنية

## هيكل المشروع
- index.html: الصفحة الرئيسية
- services.html: صفحة الخدمات
- cv-services.html: خدمة تصميم السيرة الذاتية
- jobs.html: خدمة التقديم للوظائف الخليجية
- scholarships.html: خدمة التقديم للمنح الدراسية
- digital-solutions.html: الحلول الرقمية
- portfolio.html: معرض الأعمال
- about.html: من نحن
- faq.html: الأسئلة الشائعة
- contact.html: صفحة التواصل
- css/style.css: التنسيقات العامة
- js/main.js: التفاعل والقائمة والتنقل والتصفية والتحقق
- assets/: الشعارات والرسومات التوضيحية
